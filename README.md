
# IronPulse Delivery Tracker

A MERN monorepo starter for the IronPulse Delivery Tracker.

## Project Structure

- `client/` — React frontend
- `server/` — Express backend

## Getting Started

### Frontend

```bash
cd client
npm install
npm start
```

### Backend

```bash
cd server
npm install
npm start
```

The server health endpoint is available at
`http://localhost:5000/health`.

## Lint

Run from the project root:

```bash
npm run lint
```
